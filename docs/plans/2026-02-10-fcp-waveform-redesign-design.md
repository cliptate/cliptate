# FCP 风格波形重设计

## 背景与目标
- 将波形视觉贴近 Final Cut Pro 时间线的默认音频图：连续填充、上下对称、蓝色渐变与轻微中线。
- 保持现有交互（缩放、拖拽、段落选择与播放头）不变，仅替换渲染样式。

## 范围
- **包含**：WaveformView 渲染逻辑、颜色/渐变参数、轻度平滑处理。
- **不包含**：WaveformSnapshot 生成方式、时间线压缩逻辑、任何播放或导出功能。

## 设计概述
- 继续使用单声道合并的 `WaveformSnapshot` 数据源。
- 渲染时对幅值做小窗口移动平均（轻度平滑），再应用现有 `dynamicRangeExponent` 与 `verticalGain`。
- 使用 Canvas 绘制连续闭合 Path（上/下对称），再以蓝色渐变填充并叠加中线。

## 关键渲染细节
- **路径生成**：按时间顺序生成上沿 Path，再追加反向下沿以闭合，减少大量矩形绘制带来的开销。
- **配色**：固定 FCP 风格蓝色主色 + 垂直渐变；背景保持深色半透明。
- **基线**：在中心线绘制细线，增强时间线识别感。
- **自适应采样**：继续按 `displayScale` 与 `samplesPerPixel` 计算步进，避免过密绘制。

## 错误与占位
- 继续沿用现有 placeholder / loading / error 覆盖层逻辑与文案。

## 验证与回归
- 打开波形视图检查不同宽度与缩放下的波形连续性。
- 拖拽/播放头位置应与波形对齐，段落覆盖层保持一致。
