# Cliptate v1.2

Release date: 2026-10-13 (Asia/Shanghai)
Previous version: [v1.1](https://github.com/cliptate/cliptate/releases/tag/v1.1)

## Highlights

More transcription engines, richer CLI workflows, and smoother dictation and video editing.

## Changes

- **Models:** Added multilingual Whisper and Nemotron ASR choices in AI Cut and
  Voice To Text, with shared model downloads and optional precise word alignment.
  [Model guide](https://github.com/cliptate/cliptate/blob/v1.2/docs/development.md#shared-model-cache).
- **CLI and history:** Generate speech from text, query transcript history, and
  inspect saved AI corrections to improve dictionary vocabulary. History now
  preserves correction evidence and the Restore Original baseline.
  [CLI guide](https://github.com/cliptate/cliptate/blob/v1.2/docs/cli.md).
- **Dictation:** Live previews revise growing speech windows, with more reliable
  streaming audio and new microphone indicator styles.
- **Workspace:** Unified sidebar and page layouts, improved video import and
  navigation, and removed the Free Access navigation entry in free builds.
- **Updates and AI:** The installation prompt shows verified update-signature
  status. OpenAI requests omit unsupported generation parameters.
- **Development:** Cliptate Dev uses separate app identity, settings, history,
  and CLI transport to protect production privacy permissions and data.

## Upgrade notes

- Requires Apple Silicon and macOS 15+. Update in the app, or close Cliptate and
  replace it using the DMG. Restart Cliptate before using the upgraded CLI.
- Settings, history, compatible caches, and model selections are preserved. Download
  newly selected models before first use. Old history gains no fabricated corrections.
- GitHub builds remain fully free. App Store capability and subscription rules
  are unchanged; development and production data remain separate.

## Known limitations

CLI transcription and speech generation still do not create history entries.
Nemotron live dictation uses the shared VAD pipeline rather than a native streaming
encoder cache. Real-model inference, microphone input, and update installation still require
manual validation.

## Validation

SwiftPM build, 774 tests, the direct-channel Release app build, 80 automation
tests, dependency notices, and four login-item tests with one cooperative worker
passed. Developer ID signing, notarization, and installer verification will run
in the package workflow before publication.
