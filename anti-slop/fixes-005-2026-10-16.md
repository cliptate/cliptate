# 语音听写页 · Spokenly 风格参考

本轮范围为语音听写页。用户要求 Usage 放顶部，并让 Usage 与 Dictation Indicator 默认展开；同时参考 Spokenly 优化界面风格。

## Design Read

参考 [Spokenly 官方模式页](https://spokenly.app/docs/modes) 内的 macOS 应用截图。取其紧凑的设置分组、细分隔线、浅色面板和克制的字重层级，使用 Cliptate 既有系统颜色与原生控件实现。保留听写与助手的实际配置和行为。

沿用 Apple Design、SwiftUI Expert、Anti Slop after 模式；本轮改动均由用户直接授权。ENERGY 1 / RHYTHM 1 / MOTION 1。

## 修改

- Usage 位于标题下，默认展开，使用无独立背景的统计行；重置按钮位于统计区右下。
- 内容列最大宽度 840 pt，与标题左边界对齐。
- 模型、语言位于一个紧凑设置分组，模型名称右对齐，管理入口使用链接样式。
- 听写与助手改为纵向设置分组，快捷键位于各行右侧；三个上下文开关采用自适应布局。
- Dictation Indicator 默认展开，移除外围大卡片，保留原有四种外观预览及手动收起能力。
- 无新增文案，沿用现有本地化键。

## 验证

- Full Xcode 环境下 `./scripts/build-and-run.sh build` 构建与签名通过，日志 `/tmp/cliptate-spokenly-style-build.log`。
- 重启新构建后，原生辅助功能树确认两个分区默认展开；实际收起和重新展开均通过。
- 模型管理链接进入模型库通过。
- 词典 → 文件转录 → 语音听写 → 词典 → 语音听写导航通过，标题保持可见。
