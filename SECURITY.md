# Security reports

For vulnerabilities, use GitHub's private reporting option in this repository's
Security tab when available. Otherwise, contact the maintainers through the support
link on [the Cliptate website](https://cliptate.github.io) to arrange a private report.
Avoid posting credentials, recordings, or exploit details in public issues.

Include the affected revision, macOS version, reproduction steps, and impact.
Security fixes target the current default branch; historical development builds
are not separately maintained.

Source builds do not include billing credentials or signing certificates.
External AI providers are optional and use credentials supplied by the user.
Local inference does not require those providers.
