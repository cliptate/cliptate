# Cliptate v1.1

Release date: 2026-10-12 (Asia/Shanghai)
Previous version: [v1.0](https://github.com/cliptate/cliptate/releases/tag/v1.0)

## Highlights

Native CLI, more reliable dictation, and smoother app startup.

## Changes

- **CLI:** Batch-transcribe audio/video to text, JSON, Markdown, SRT, or VTT;
  manage custom vocabulary. Install from Settings → Command Line.
  [CLI guide](https://github.com/cliptate/cliptate/blob/v1.1/docs/cli.md).
- **Dictation:** Clear microphone diagnostics, better handling of trailing speech,
  and saved live transcripts when final recognition fails.
- **Startup:** Added login-at-startup settings and moved system queries off the UI
  thread. CLI launches run in the background without opening the main window.
- **Models:** Updated MLX inference dependencies and improved compatibility for
  transcription, diarization, and speech synthesis.

## Upgrade notes

- Requires Apple Silicon and macOS 15+. Update in the app, or close Cliptate and
  replace it using the DMG. Verify the download with its SHA-256 file.
- Direct builds now run without App Sandbox. Missing settings, presets, and history
  are copied from the previous sandbox; originals and existing direct-build data
  are preserved. Compatible Hugging Face model caches are reused.
- Install the CLI after moving the app to Applications, add `~/.local/bin` to
  `PATH`, and restart Cliptate after upgrading.

## Known limitations

The CLI accepts local files, processes one transcription at a time, and does not
create projects or history entries. App Store builds retain their sandbox,
subscription, and Accessibility restrictions and do not include the CLI.

## Validation

SwiftPM builds and tests passed in both channels (704 tests each), along with the
Release app build and 62 automation tests. The published package passed Developer
ID signing, Apple notarization, and Gatekeeper checks; the signed update feed is
available. Hardware/model inference and interactive microphone, login-item, and
Sparkle installation checks were not manually performed.
