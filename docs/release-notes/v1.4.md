# Cliptate v1.4

Release date: 2026-10-16 (Asia/Shanghai)
Previous version: [v1.3](https://github.com/cliptate/cliptate/releases/tag/v1.3)

## Highlights

A new Home dashboard, a year of activity at a glance, and clearer native controls throughout the workspace.

## Changes

- **Home:** View all-time dictation duration, generated words, estimated time saved,
  a rolling 12-month activity heatmap, and record counts by source.
- **History:** Activity counts survive normal transcript/audio expiry. Browse a
  steadier list/detail layout, clear history by source, and find copy, playback,
  re-transcription, and Finder actions together.
- **Dictation:** Escape cancels active dictation from any app in the direct-download
  build, including sessions started from the interface and during model preparation.
  Fixed a microphone callback crash when starting dictation.
- **Workspace:** Refined sidebar navigation, native controls, dictation and speech
  generation pages, model/settings pages, and editing/export panels. Updated all
  five interface languages and Home screenshots.
- **Builds:** App, CLI, and shared Core now use one SwiftPM graph. Release linker
  optimization and symbol stripping are retained.

## Upgrade notes

- Requires Apple Silicon and macOS 15+. Update in the app, or quit Cliptate and
  replace it using the DMG. Verify SHA-256 and restart before using the CLI.
- Existing settings, history, model caches, and production identity are retained.
  Remaining history automatically seeds activity metadata; no manual migration is
  needed. Global Escape requires Accessibility permission in the free GitHub build.

## Known limitations

Activity cannot recover already expired or deleted records; time saved is an
estimate. CLI requests still create no history entries. App Store shortcut limits
are unchanged. Real-model, microphone, and end-to-end update checks remain manual.

## Validation

SwiftPM build and test suites passed (836 tests, seven opt-in model checks
skipped), as did the direct-channel Release app build, four login-item tests with
one cooperative worker, 92 automation tests, and dependency notices. Developer ID
signing, notarization, privacy-identity comparison, and final installer verification
will run in the package workflow before publication. Real-model inference,
microphone input, and an installed v1.3-to-v1.4 update were not manually verified.
